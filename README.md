# ENGLSH — English Learning Platform

A PC-first adaptive English training platform for B1+ to C1 learners.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

All progress is saved automatically in your browser's localStorage — nothing resets between sessions.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Zustand (persisted to localStorage)
- Lucide React icons
